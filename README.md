## The repository is built with ReactJS (Typescript)

**Version**:
- Node: v16.16.0
- NPM: 8.11.0
- YARN: 1.22.19

**Install**: npm i / yarn (yarn is recommended)

**Start**:
- Development:
    - cp .env.dev
    - npm run dev

**Build**:
- npm run build / yarn build (yarn is recommended)
- npm run preview / yarn preview (yarn is recommended)
